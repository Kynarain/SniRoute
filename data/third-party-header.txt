THIRD-PARTY LICENSES
====================

sniroute itself is licensed under GPL-3.0-only; the full text is in LICENSE.

This document lists every third-party component that ships inside the installer
or the portable ZIP, and then reproduces each one's license text IN FULL at the
end. The appendices are not summaries - they are the verbatim license texts, so
this single file is self-contained and can be read without opening anything else.

Why so many components for one small tool: the tool is a thin orchestrator. It
runs a Python DoH server, a nginx TLS front end and an OpenSSL certificate
toolchain, each as a separate process. Those runtimes carry their own
dependencies (OpenSSL inside Python, PCRE2 and zlib inside nginx.exe, and so on),
and each one has licensing terms attached. Listing them is the honest option.

--------------------------------------------------------------------------------
How these components are used
--------------------------------------------------------------------------------

  CPython          runs tools\doh_ech.py (the local DoH server) and
                   scripts\sniroute.py (certificates, nginx control, self-tests).
  OpenSSL          issues the local root CA and the leaf certificates; also
                   provides TLS for the DoH endpoint and for Python's ssl module.
  nginx            terminates TLS for the proxied host names and forwards to the
                   upstream origin without exposing the blocked server name.
  PCRE2 / zlib     nginx's own regex engine and compression, compiled into
                   nginx.exe and never called by sniroute directly.
  libffi / expat   pulled in by the Python build (ctypes, XML parsing).
  SQLite / Tcl/Tk  part of the official Python distribution; not used by
                   sniroute, kept because the upstream build ships them.
  VC++ CRT         the C runtime the Python DLLs link against.

  Every component runs as a separate process. None is statically linked into
  Sniroute.exe, so any of them can be replaced with a different build without
  rebuilding sniroute.

--------------------------------------------------------------------------------
What is NOT bundled
--------------------------------------------------------------------------------

  * No Java runtime. The tray application is native Win32 code; the earlier
    Java-based GUI remains in the repository as history and is not shipped.
  * No third-party DoH client library: the DoH server uses only the Python
    standard library.
  * No telemetry, crash reporting or update service of any kind.
